# ChurnGuard — Customer Churn Predictor

[![MIT License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Python 3.9+](https://img.shields.io/badge/python-3.9%2B-blue.svg)](https://python.org)
[![Flask](https://img.shields.io/badge/flask-3.x-lightgrey.svg)](https://flask.palletsprojects.com)

An open-source, end-to-end ML pipeline that predicts bank customer churn, explains the result using GPT-4o, and generates a personalized retention email — all from a single web form.

## Features

- **5 ML models** — XGBoost, Random Forest, Decision Tree, SVM, KNN trained with GridSearchCV hyperparameter tuning
- **Ensemble scoring** — average probability across all models shown alongside individual model scores
- **Interactive charts** — doughnut chart for overall churn probability, horizontal bar chart comparing all models (Chart.js)
- **AI-powered insights** — GPT-4o explains why the customer is or isn't at risk, grounded in their specific data
- **Retention email** — personalized email generated and ready to copy with one click
- **130+ countries** — geography dropdown covers Europe, Middle East, Asia Pacific, Americas, and Africa
- **Responsive UI** — clean Tailwind CSS design that works on mobile and desktop

## Quick Start

**1. Clone and install**

```bash
git clone https://github.com/shraddharaom/customer-churn-prediction.git
cd customer-churn-prediction
pip install -r requirements.txt
```

**2. Add your OpenAI key**

```bash
# .env
OPENAI_API_KEY=sk-...
```

**3. Train the models**

Download `churn.csv` from [Kaggle](https://www.kaggle.com/datasets/shubhammeshram579/bank-customer-churn-prediction) and place it in the project root, then:

```bash
python train.py
```

This trains all 5 models and saves them to `models/`.

**4. Run the app**

```bash
python app.py
```

Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your browser.

## Deployment

For production, use gunicorn:

```bash
gunicorn app:app
```

The included `Procfile` makes it one-click deployable to Railway or Heroku.

## How It Works

1. User fills in customer data (demographics, financials, account status)
2. Flask preprocesses the form data and runs inference through all 5 ML models
3. The average churn probability and per-model scores are returned
4. OpenAI GPT-4o receives the customer profile + predictions and generates:
   - A 2–4 sentence explanation of why the customer is or isn't at risk
   - A warm, personalized retention email addressed to the customer by name
5. Results are displayed with animated charts
